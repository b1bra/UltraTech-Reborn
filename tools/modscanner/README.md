### Mod Scanner



#### Purpose



This tool analyzes Minecraft mod files and collects information required for project documentation.



###### Features



\- Scan mod folders.

\- Read mod metadata from jar files.

\- Detect mod name, version, mod id and authors.

\- Generate modlist documentation.



###### Usage



The tool will analyze a selected mods folder and update the project mod list.
